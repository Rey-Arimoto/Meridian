This directory contains the **frozen, immutable artifacts** of Meridian v0.1.

These documents represent the first complete implementation of:
- Entropy as a state variable
- Non-intervention (Freeze / NoOp) as a first-class decision
- Entropy Regime–based Alpha
- Constitutional safety before profit maximization

  The philosophical and architectural vision of Meridian at v0.1.

- `entropy_spec.md`

- `alpha.md`  
  Definition of Meridian’s first Alpha based on Entropy Regimes.

- `decisions.md`  
  Architectural Decision Records (ADR) up to v0.1.
